# SmokenPackz 🌿

Premium OSRS accounts & gold marketplace. Crypto checkout. Discord community.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deployed on Netlify. Connect your repo and it auto-builds.

## Customization

Before going live, update these in `src/data/products.js`:
- `discordUrl` — your Discord invite link
- `cryptoOptions` — replace `YOUR_*_WALLET_ADDRESS` with real wallet addresses
- `products` — add/edit/remove products

## Tech Stack
- React + Vite
- TailwindCSS (custom OSRS + stoner theme)
- React Router (HashRouter for static hosting)
- Lucide icons
